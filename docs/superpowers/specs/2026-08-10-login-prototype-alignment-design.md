# 登录页原型对齐设计

状态：已确认
日期：2026-08-10
范围：`engineering-platform` 登录页视觉外壳与登录表单展示文案

## 背景

当前 `/login` 已实现 V0.2 两步认证：员工编号与密码验证成功后，再进入 TOTP 验证。该认证状态机、Problem Details 错误呈现、Session 刷新和安全回跳均已由测试覆盖，不能为了复刻旧原型退回“账号、密码、TOTP 同屏提交”。

当前页面虽然已经是双栏结构，但与已确认的 Claude Design 原型仍有明显视觉差异：缺少 56px 顶部品牌栏，Hero 文案、交付阶段、留白和右侧卡片位置不一致，右侧整栏边界过重，品牌名称和版本信息也未按原型呈现。

## 目标

在不改变认证契约的前提下，使登录页在 1440×900 桌面视口下贴近原型：

- 顶部呈现“研发协作平台”品牌与“集团内网 · V0.2”。
- Hero 使用“需求到合并，一条可治理的 AI 交付链路。”，其中“可治理”为品牌橙。
- 交付链路展示“需求对齐 → Spec / Plan 规格计划 → 开发 → Review 评审 → MR 合并”。
- 右侧登录卡片的位置、宽度、圆角、边框和阴影与原型一致。
- 保留 light/dark/system 主题与现有窄屏响应式能力。
- 保留 V0.2 两步认证，不增加演示账号、登录绕过或前端推算的 TOTP 倒计时。

## 方案选择

采用“精确重构页面外壳，保留现有 `LoginFlow`”方案。

未采用以下方案：

- 不重写整个表单：会重复实现已经验证的认证状态机和错误恢复。
- 不只做局部 CSS 修补：无法解决品牌栏、Hero 层级、阶段链路和右侧版式的结构差异。

## 页面结构

`LoginPage` 继续只负责路由页装配和 Session 刷新，页面结构调整为：

1. `<main>`：全视口背景与整体布局。
2. 顶部品牌栏：左侧品牌标识和“研发协作平台”，右侧版本信息与主题选择器。
3. Hero：Eyebrow、两行主标题、交付阶段链路和底部版权信息。
4. 登录区域：固定桌面宽度的卡片容器，内部继续渲染 `LoginFlow`。

登录页复用 `BrandMark`。若其固定文案阻碍登录页展示，最小增加可选 `name` 属性，默认值仍为“内部研发平台”，因此侧栏和其他调用方不变；登录页传入“研发协作平台”。

## 视觉规则

### 桌面视口

- 设计基准为 1440×900；页面最小高度为 `100vh`。
- 顶部品牌栏高度 56px，左右内边距 44px。
- Hero 左侧内边距 88px，保留足够呼吸空间。
- 登录区域桌面宽度 460px，右侧留白 88px；卡片占满剩余内容宽度。
- 主标题约 50px、粗体、1.28 行高；只高亮“可治理”。
- 阶段节点使用轻边框胶囊，节点间以品牌橙箭头连接，最后的“MR 合并”为深色实心节点。
- 登录卡片为 14px 圆角、轻边框、低对比阴影和 32px 内边距。
- 页面底部显示“© 2026 集团企业开发部 · 仅限内网使用”。

颜色优先使用 antd token；品牌橙复用 `BRAND_ORANGE`。light 主题接近原型的暖白背景，dark 主题使用同一信息层级的 token 映射，不硬编码浅色孤岛。

### 响应式

- 1280px 及以上保持原型的横向双栏结构。
- 中等宽度减小左右留白与标题字号，但仍保持双栏可读性。
- 小屏改为纵向布局：品牌栏保持可用，Hero 在上、登录卡片在下，不产生全局横向滚动。
- 主题入口始终可通过公开按钮访问。

## 登录流程

`LoginFlow` 行为保持不变：

1. 凭据步骤标题调整为“账号登录”，展示员工编号和密码。
2. 成功后切换到“验证动态码”，自动聚焦 TOTP 输入框。
3. `BOOTSTRAP`、429、普通凭据错误、TOTP 错误和 challenge 失效仍使用现有处理。
4. TOTP 成功后仍先刷新 `me`、navigation 与 Initial State，React commit 完成后才导航。

不复制旧原型中的同屏 TOTP、演示数据重置、前端验证码倒计时或绕过认证能力。

## 测试与验收

严格按 TDD 执行：先扩展现有测试形成真实 RED，再实现视觉结构。

自动化检查：

- 登录页公开结构包含品牌、版本、主标题、五个阶段和主题入口。
- 主标题的“可治理”可独立识别并保持标题整体可访问名。
- 凭据与 TOTP 仍分步出现，不同时暴露三个字段。
- 现有登录成功、错误、429、Bootstrap、Session commit 与安全 redirect 测试全部保留。
- `BrandMark` 默认调用方行为不变，自定义品牌名仅影响显式传参实例。
- focused Vitest、`pnpm lint`、`pnpm test` 全绿。

浏览器验收：

- 1440×900 light 与 dark 下核对顶部栏、Hero、阶段链和登录卡片。
- 1280px 下无裁切；窄屏无全局横向溢出。
- 主题菜单可打开，凭据步骤提交后 TOTP 自动聚焦。

## 非目标

- 不提供临时演示账号或免认证入口。
- 不恢复旧 V0.1 三字段同屏登录。
- 不调整 Bootstrap 初始化向导视觉。
- 不修改登录 API、DTO、Cookie、权限或 Session 生命周期。
- 不重构其他页面品牌或应用 Shell。
